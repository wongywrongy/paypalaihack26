Under the hood

Who decides what

LLM · language and ideas SOLVER · math CODE · authority PAYPAL · money
Step Done by Guarantee
Turn a request into a routine LLM Picks only from the catalog and explains each pick. Can’t set prices or charge anyone.
Pick a shop for each item and build one box SOLVER Cheapest all-in combination across shops, free-shipping lines and stock. Skips items a shop won’t send to that country.
Price the box for the destination CODE Duty, tax and shipping from a dated rate table with sources. Shown before payment, never after.
Approve the total as a PayPal hold PAYPAL Orders v2 authorization in the shopper’s currency. The hold is the ceiling; code also enforces it, since PayPal allows captures above a hold.
Suggest offers and read the shop’s replies LLM Ideas and words only. Replies are parsed into a fixed offer format; text like “ignore your rules” changes nothing.
Check every offer SOLVER Recomputes the all-in total. Swaps and extras pass only if the shopper turned that rule on and the total drops.
Score offers for each shop CODE Lowest prices live in code. The shop’s language model sees scores, never the floor.
Accept or stop CODE Accept only below the hold and above every floor. At most 3 replies per shop. The language model never accepts.
Charge, release, pay shops, track PAYPAL Capture the final total; the rest of the hold is released. Shops paid by PayPal Payouts; tracking added to the payment.
